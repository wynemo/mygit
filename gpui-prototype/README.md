# MyGit GPUI 原型

独立的 Rust + GPUI 桌面原型，用于验证提交历史和双栏 Diff 的迁移方案。

## 迁移计划

完整的分阶段任务、依赖和验收条件见 [迁移清单](MIGRATION.md)。

## 启动

在项目根目录执行：

```sh
cargo run --manifest-path gpui-prototype/Cargo.toml -- .
```

最后一个参数可以替换为任意本地 Git 工作区路径。窗口内的“打开仓库”支持选择其他目录；“刷新”重新读取仓库并返回全部变更。

左栏提供三个只读分组：

| 分组 | 左侧 | 右侧 |
| --- | --- | --- |
| 全部变更 | HEAD | 工作区磁盘内容 |
| 已暂存 | HEAD | index 暂存内容 |
| 未暂存 | index 暂存内容 | 工作区磁盘内容（包含未跟踪文件） |

同一文件暂存后再次修改，会在后两个分组中显示不同版本。文件标题栏的“上一处 / 下一处”按差异块定位并突出当前块；两侧同步移动，首尾按钮禁用。单击任一侧文本后，该侧获得键盘焦点：Cmd/Ctrl+C 复制、Cmd/Ctrl+A 全选，方向键移动光标，Shift+方向键扩选；Home/End 定位行首尾，Cmd+上下或 Ctrl+Home/End 定位全文首尾，配合 Shift 扩选。Alt+上下定位上一处/下一处差异。历史和文件列表的通用键盘交互仍归 F06。

支持鼠标跨行拖选、Shift+单击扩选，以及拖到视口边缘自动滚动。复制保留原始制表符、空行、CRLF/LF 和末尾换行，不包含行号或 Diff 对齐占位行。工具栏的全选/复制作用于最后选中的一侧，默认右侧。

按文件类型显示基础语法高亮，未知类型退回纯文本；左右共用暗色主题与字体设置。“字号 − / +”同时调整两侧字号，当前只在本次运行中保留。

本原型固定使用 GPUI 0.2.2，提交 Cargo.lock。当前验证目标为 macOS，要求 Rust、Git、完整 Xcode 和 Metal Toolchain。若编译提示 Metal Toolchain 缺失：

```sh
xcodebuild -downloadComponent MetalToolchain
```

## 已实现

- 打开本地仓库、显示分支、查看每页 100 条当前 HEAD 的提交。
- 分别查看全部、已暂存、未暂存变更，正确区分 HEAD、index、磁盘和未跟踪内容。
- 点击提交查看变更文件，点击文件查看行号对齐的双栏只读 Diff。
- 工作区比较 HEAD 与磁盘文件；历史比较首个父提交与选中提交，初始提交与空内容比较。
- 删除与新增行底色、统一的左右滚动、通过文件标题栏 ← / → 同步横向移动长行、虚拟列表。
- 后台执行 Git 和 Diff，忽略切换操作后迟到的结果。
- 按差异块导航、显示块计数和当前块，首尾禁用，支持新增/删除/替换块。
- 两侧独立的文本选区、全选/复制、只读键盘操作，原始字节与渲染中的制表符展开分别映射。
- 基础语法高亮及多行语法上下文，Diff 底色与选区背景独立绘制，左右字号同步调整。
- 二进制、非 UTF-8 和大文件提示；内容合计超过 2 MB 暂不生成 Diff。

## 验证

Git 数据层可脱离图形依赖运行：

```sh
cargo test --manifest-path gpui-prototype/Cargo.toml --no-default-features
cargo check --manifest-path gpui-prototype/Cargo.toml
```

测试在临时仓库中验证暂存后再次修改、空仓库、未跟踪文件、重命名、初始提交、合并首父比较、删除后重建、二进制及差异块对齐/导航、原始文本复制、Unicode 字符边界与多语言高亮；不修改用户仓库。

## 本机验证结果

已通过 macOS 编译、82 项数据层、导航、选区和高亮测试及 Clippy 检查。已实际启动窗口，验证提交选择、文件切换、左右垂直滚动、横向移动按钮，以及原生目录选择器。另在临时仓库中验证已暂存/未暂存版本区分、差异块定位和首尾禁用。文本交互验证覆盖跨对齐占位行拖选、实际复制/粘贴内容、Shift+方向键、Cmd+A、字号调整、Python/Rust/JavaScript 高亮及切换文件清理选区。

## 当前边界

编辑、保存、暂存/提交、推拉、分支管理、历史搜索、Blame 和配置持久化已实现，后续新增界面流程仍待窗口验证。文件快速定位、全项目搜索和 AI 提交信息尚待迁移。全部变更视图显示 HEAD 与磁盘的总体差异；已暂存和未暂存分组分别读取对应内容。未合并的 index 条目目前只显示冲突提示。子模块暂未提供专用视图。非 UTF-8 文件名会提示不支持，避免替代字符指向错误路径。

列表采用虚拟渲染，但文本和差异行仍保存在内存中，尚未做性能或内存基准测试。Windows/Linux 尚未验证；新版本 GPUI 的平台支持和 API 不等同于固定的 0.2.2。

## 代码结构

- `model.rs`：仓库数据、比较端点、重命名路径与差异块。
- `git.rs`：Git CLI 查询和各版本内容读取。
- `diff.rs`：纯文本对齐和差异计算。
- `text.rs`：原始文档、UTF-8/字素边界、选区及制表符显示映射。
- `syntax.rs`：共享语法定义、暗色主题与后台高亮。
- `state.rs`：不依赖 GPUI 的应用状态和差异导航。
- `tasks.rs`：后台任务与迟到结果检查。
- `app.rs`：界面事件与数据加载的衔接。
- `views/`：工具栏、历史/文件列表、Diff 视图。
- `main.rs`：启动与窗口生命周期。

行内改动使用更深的红/绿背景标记，保留语法颜色；换行约定变化显示 LF、CRLF 或“无末尾换行”标签。标签不会被复制。

提交历史滚动到尾部加载更多，全部分页固定到本次打开的 HEAD；选中提交显示完整正文及元数据。Tab/Shift+Tab 在历史、文件与 Diff 间切换，列表上下选择、回车进入下一栏。Cmd/Ctrl+O 打开、+R 刷新、+1/+2/+3 切换变更分组，Esc 取消读取。

“设置 / 最近仓库”可调整字体与面板宽度；重启恢复最近仓库和设置。默认兼容 `~/.git_manager/settings.json`，保留未知字段，损坏配置先备份；验证时可用 `MYGIT_CONFIG_DIR` 指定独立配置目录。Git 读取有 30 秒超时和取消入口。

文件树与按完整路径区分的标签页已实现，支持关闭当前/其他/全部及保留各页只读浏览位置；自动化验证通过，窗口交互回归待进行。

工作区比较可进入编辑器：Cmd/Ctrl+S 保存，+Z 撤销，+Shift+Z 重做，+F 查找，F3/Shift+F3 跳转匹配。保存检查磁盘冲突，关闭未保存文件会提示。编辑器/输入法的窗口回归暂未进行。

变更列表支持勾选多文件及暂存/取消暂存全部，提交面板仅提交 index。Git 写操作串行执行，错误与 hook 输出显示在界面；提交草稿按仓库保留。相关窗口回归待进行。

支持双栏/统一 Diff 切换、任意提交比较和选中提交与工作区比较（只读）；触控板横向或 Shift+滚轮同步横移。预览前检查对象类型和大小，符号链接展示链接目标、子模块展示提交引用。默认 2 MB，显式按需预览最高 20 MB，最多 200000 行。对应窗口回归待进行。

工作区 Diff 支持“还原文件 / 还原当前块”，确认框显示来源和目标。全部变更以 HEAD 为来源，未暂存以 index 为来源；均保持暂存区不变。恢复记录保存在配置目录的 `recovery/` 下，“撤销还原”可恢复磁盘内容及权限；若还原后文件又被外部修改，撤销拒绝覆盖。未保存的编辑内容须先处理。该功能的临时仓库测试通过，窗口流程待验证。

工作区及 Git 元数据变化会合并后自动刷新；手动刷新、窗口重新聚焦和 Git 写操作结束也会触发更新。刷新保留当前模式、标签页、目录展开、选区与滚动位置，更新已保存内容；未保存内容继续保留并提示外部变化。监听失败时使用定期刷新，并显示原因。自动刷新已通过本机文件事件和临时仓库测试，窗口聚焦与位置保持待验证。

“分支”面板显示本地/远程引用、当前分支、upstream 及领先/落后状态，支持新建、切换和远程跟踪检出。选择分支可设为新分支起点；新建分支名输入框也可指定远程检出的本地名。右击提交可筛选指向它的分支；分支列表支持上下键及回车切换。未保存编辑内容会阻止切换，磁盘未提交修改由 Git 的正常检出保护处理。分支操作已通过临时仓库测试，窗口交互待验证。

分支面板可指定远程执行 Fetch/Pull/Push、将选中分支合并到当前分支，或对“新分支起点 / Reset 目标”执行 soft/mixed/hard Reset。网络操作在后台运行并显示进度，沿用 Git 凭据与 SSH 配置；失败保留非快进、认证及冲突说明。Reset 会先显示影响和固定目标的确认框，并在执行前再次检查当前 HEAD/分支。hard 会丢弃未提交内容，确认框明确说明该影响。上述数据路径已通过本机临时仓库测试，窗口及真实凭据交互待验证。

“历史搜索”可按消息全文、SHA 或作者搜索整个指定提交范围，附加作者和日期过滤；范围可输入 HEAD、分支、标签、提交或 ALL。查询会固定起点并分页，清除过滤恢复普通历史。“当前文件历史”以及文件树的历史入口可查看完整路径的文件/目录记录，文件会跟随重命名；查询结果仍可查看详情、受影响文件及与工作区比较。上述数据路径已通过跨批次、分页及重命名测试，窗口流程待验证。

Diff 工具栏的“Blame”显示各侧版本的逐行作者与 SHA，编辑器也支持未保存内容。悬停可查看提交详情，点击跳转到历史，右键复制 SHA；未提交行明确标记。数据读取在后台执行，可取消，不改写工作区或暂存区。已通过 CRLF、重命名、未保存内容及 SHA-256 仓库测试，窗口交互待验证。

提交历史已显示 DAG 节点、分支颜色、合并边和当前引用标签，选择与分页沿用历史列表。普通历史及无过滤的范围查询追加分页时保持已有节点布局；过滤结果中缺失的父提交使用短灰线提示。引用标签独立刷新，移动分支或删除标签不依赖 HEAD 变化。数据测试通过，窗口布局待验证。

合并提交三栏的数据层已实现：读取固定的两位父提交和结果，合并双方文件列表，按结果行对齐三侧并保留各侧原路径、行号和原文。三栏界面已接入历史入口，支持双方文件并集、同步滚动、差异导航、语法高亮、字号调整、原始行/整侧复制、版本中缺失文件提示及按需 20 MB 预览。标签页保留三栏数据、滚动和导航位置，刷新保留固定历史缓存。三侧现均支持原文选区、鼠标拖选、Shift 选择、全选/复制及各版本 Blame；切换标签保留第三侧选区，切回双栏清理不兼容位置。窗口验收仍待进行。
