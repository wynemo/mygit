# 原生窗口验证记录

日期：2026-10-04。环境：macOS 26.6（25G72）、GPUI 0.2.2、debug 构建。

本轮使用独立的 `MyGit Validation.app`、临时 Git 仓库及独立 `MYGIT_CONFIG_DIR`。仓库包含中文/空格文件名、CRLF、emoji、组合字符、暂存后再修改的文件，以及两位父提交的合并历史。AI 仅连接本机模拟 HTTP 服务，密钥为测试字符串；未发送真实项目内容或真实凭据。

## 已观察并复验的修复

| 问题 | 修改 | 原生复验 |

## 未保存内容、磁盘冲突与还原复验

- 编辑器追加未保存的 `// dirty-buffer-KEEP` 后关闭标签，弹出保存/放弃/取消三项提醒；取消保留标签及完整缓冲区。
- 外部向同一磁盘文件追加 `// external-conflict-KEEP`，窗口提示磁盘变化且保持未保存输入。点击保存显示冲突错误；CLI 核对外部内容仍在，未保存输入没有覆盖磁盘。
- 再次关闭并选择“保存并继续”，保存失败后确认框和标签仍在；选择放弃后仅关闭缓冲区，磁盘外部内容保留。
- 整文件还原确认显示 HEAD 固定 SHA、工作区目标、index 保持原样及恢复策略。确认后磁盘与 HEAD 完全一致，index 不变；点击撤销还原，外部修改和原有未暂存内容恢复。
- 导航到差异块后执行“还原当前块”，确认框明确范围；单块样例还原后 Diff 清空，磁盘与 HEAD 一致。该样例只有一个差异块，尚不能证明多块还原隔离、index 来源及全部特殊文件流程。
- W03 的输入法组合仍待验，W08 的未保存编辑拒绝、index 来源和多块/特殊状态原生回归仍待验；本批未整体勾选。
